
## *Cool chat system for BBC micro:bit with gd hitboxes memes.*

Ledgend

* A = send *accurate* hitboxes 
* B = send *negative* hitboxes 
* A+B = send *inaccurate* hitboxes 

**USES RADIO FOR COMMUNICATION**


## Use as extension in MakeCode

This repository can be used as **extention** in MakeCode

* open [https://makecode.microbit.org/](https://makecode.microbit.org/)
* Click on *New project*
* Click on *extensions* after the gear menu
* Search for **https://github.com/aidenonlinux/gd-hitboxes-memes-chat** and import

## Edit this project

To edit this project in MakeCode:

* open [https://makecode.microbit.org/](https://makecode.microbit.org/)
* Click on *Import* and click *Import URL*
* paste **https://github.com/aidenonlinux/gd-hitboxes-memes-chat** and click on import
